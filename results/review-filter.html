Preview filter

Urutan tetap: gamma → exposure digital → brightness → shadows → sharpness. Gamma memakai eksponen langsung (di bawah1 mencerahkan midtone, di atas1 menggelapkan); exposure dalam EV digital; brightness adalah offset intensitas; shadows mengangkat/menurunkan nilai gelap per channel; sharpness memakai unsharp 3×3. Semua default identitas/raw. Filter tidak melakukan crop atau resize.

Profil weekday/weekend × pagi/siang/sore/malam tersimpan terpisah. Setelan per video adalah snapshot eksplisit: mengubah profil tidak diam-diam mengubah video lain. Tidak ada pemaksaan jumlah video menjadi delapan.

Belum ada video dipilih. File asli tetap lokal; halaman tidak mengunggah video atau mengubah file asli.

Buka melalui localhost bila browser menolak hashing file. Pengaturan terakhir disimpan di browser ini; ekspor JSON untuk dibawa ke Kaggle. Raw baseline harus tetap diuji. Keandalan malam belum dibuktikan.
