2. Run All. Cell awal menampilkan GPU yang benar-benar dialokasikan; selain L4 ditolak.

5. Ikuti dialog login Google. Akun itu harus punya akses sumber, query BigQuery dan baca/tulis hasil. Tidak perlu menempelkan service-account JSON. Kredensial tidak dimasukkan ke ZIP hasil atau GitHub.
6. Buka GRADIO_PUBLIC_URL. Isi KDTK4karakter, Nama Toko, Latitude dan Longitude. Pilih Area Coverage dan Process; tidak perlu video.
7. Buka RESULT dan Buka hasil BQ untuk job yang sama. Periksa tabel Area, kompetitor, Indomaret dan peta pan/zoom/layer. Pastikan hasil GCS/BQ terbaca kembali. Penerimaan HTML oleh viewer tidak membuktikan tile/CDN tersedia di browser.
8. Traffic/PPAC dibuka setelah hasil Area Colab L4 terbaca kembali, dengan target/periode/koordinat/versi yang cocok. Gunakan upload video atau gs:// pada slot. Path lokal opsional hanya /content/videos/. Dataset Kaggle tidak otomatis tersedia.
9. Traffic boleh subset video; PPAC tetap membutuhkan seluruh observasi wajib, termasuk shift3 untuk jam>15. Hasil hilang bukan nol.
10. Setelah job selesai, hentikan cell server. Unduh paket diagnosis dari Gradio atau jalankan cell unduh terakhir. Simpan job_id sebelum runtime Colab berakhir.

PERBAIKAN SETUP r2
Output setup/verify/preflight diteruskan melalui Python notebook, ditampilkan live dan disimpan ke setup.log/runtime-check.log/cloud-preflight.log.
Tahap setup disimpan ke setup-status.json. Jika gagal, RuntimeError menyebut tahap, exit code dan tail error asli.
Retry memakai micromamba install pada prefix conda yang sudah ada; tidak mereset environment. Wheel aplikasi dipilih eksplisit, sehingga sisa wheel lama tidak dipakai.
Cell unduh diagnosis terakhir tetap berfungsi bila setup gagal sebelum SCIENCE tersedia. ZIP diagnosis menyertakan tail log terbatas dan tahap gagal, tanpa credential.
Traceback CalledProcessError dari notebook lama hanya membuktikan bootstrap exit1; penyebab sesi owner belum diketahui. Host Python3.13 belum terbukti sebagai penyebab; aplikasi tetap memakai Python3.12 terisolasi.
Gunakan revisi notebook terbaru. Salinan lama di Colab tidak otomatis mengikuti perubahan GitHub. Jangan menghapus /content atau meng-upgrade dependency secara acak untuk mencari penyebab.
